# React Bits (copy/paste components)

This folder is intentionally designed for **copy/paste** React Bits components (no npm installs).

## What you (Ben) will paste

From the React Bits site (use the **Code** tab for each component), paste the component source into:

- `GradientText.jsx`
- `HoverTilt.jsx` (or `TiltedCard.jsx` if that’s the component you choose)
- `ClickSpark.jsx`
- `ScrollReveal.jsx`
- `FlowingMenu.jsx` (optional; only if we swap the navbar)

If React Bits provides CSS for a component, paste it into `reactbits.css` (or keep it colocated if the snippet expects that).

Docs: `https://reactbits.dev/get-started/index`
